# Creative Hub Global

Сделай сайт для творческого объединения на основе технического задания из файла. Поддержка трех языков - испанский аргентинский (базовый), английский и русский. Визуальные референсы прикрепляю картинками.  Тексты и картинки пока заполни выдуманной информацией, позже отправлю реальную инфу. Пока нужно поработать над структурой и дизайном.
